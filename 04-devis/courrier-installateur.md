## Cahier des charges du devis (annexe au courriel)

Le devis est destiné à un dossier de subvention FIPDR : il sera transcrit ligne à ligne dans le
plan de financement. La base éligible est **plafonnée à 15 000 EUR par caméra, coût d'installation
et de raccordement compris**. Les modalités suivantes sont donc impératives.

### Structure imposée : un sous-total par caméra

| Poste | CAM 7 (site D, entrée Vaubécourt) | CAM 8 (site E, rue du Moulin) | CAM 9 (site F, rue de Soisy) |
|---|---|---|---|
| Caméra et accessoires (modèle, optique) | | | |
| Support / mât / fixation | | | |
| Pose et paramétrage | | | |
| Raccordement Ethernet vers le système (part imputée à la caméra) | | | |
| Alimentation électrique strictement nécessaire (ligne dédiée, armoire, protection) | | | |
| Connectique réseau (câblage, prises, éventuels équipements intermédiaires) | | | |
| **Sous-total par caméra (HT)** | | | |

- **Le câblage Ethernet et l'alimentation électrique dédiée doivent être imputés par caméra**,
  jamais en poste séparé transversal : c'est la règle d'éligibilité FIPD 2027.
- Le cheminement des câbles vers les sites D, E et F doit être décrit
  (linéaire, mode de pose aérien/souterrain, gaines, éventuels équipements intermédiaires).
- **Confirmer la faisabilité Ethernet** : si un segment dépasse environ 100 m, indiquer la solution
  proposée (équipement intermédiaire, ou alternative à chiffrer séparément) **avant** tout engagement.

### Postes distincts (hors base « par caméra »)

- **Réorientation de la CAM 1** vers les abords de la mairie et de la salle des fêtes : intervention
  à chiffrer en poste distinct (sans acquisition, hors base éligible FIPDR ; financement communal).
- **Commutateur PoE additionnel** : le commutateur existant (DH-PFS3110-8ET-96, 8 ports PoE) sera
  saturé ; le passage à 9 caméras impose un équipement PoE supplémentaire, en poste distinct.
- Onduleur du système, armoire, précisément ce qui est strictement nécessaire aux caméras.
- Signalétique : **panonceaux déjà en place** ; rien à chiffrer.

### À exclure du devis (non éligibles FIPDR)

- Maintenance récurrente, abonnements, consommation électrique.
- Renforcement de réseau profitant au village, mise aux normes de l'éclairage public.
- CSU, déports d'images vers police/gendarmerie (non prévus : consultation sur réquisition).

### Mentions attendues

- Prix **hors taxes et TTC**, validité du devis couvrant **l'année 2027** (opérations à réaliser en 2027).
- Individualisation de chaque caméra : repère, localisation, modèle, caractéristiques
  (résolution, angle de champ, vision nocturne).
- **Validité de 90 jours minimum** et mise à disposition des capacités de l'entreprise
  (attestation de vigilance URSSAF si marché formalisé).
