# 04 - Devis détaillés

À déposer dans ce dossier :

- [ ] Devis détaillé n°1 (PDF, nommé `devis-1-[FOURNISSEUR].pdf`)
- [ ] Devis n°2 et suivants le cas échéant
- [ ] Le devis retenu doit correspondre ligne à ligne au plan de financement (03) et au dossier technique (05)

Conseils :
- Chaque caméra doit être individualisée (repère, localisation, modèle).
- Faire apparaître séparément matériel, pose, génie civil, maintenance.
- Conserver la traçabilité du choix du prestataire (code des commandes publiques : adaptation des modalités selon les montants).
