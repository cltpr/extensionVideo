# 02 - Autorisation préfectorale de vidéoprotection

Deux cas de figure, à documenter dans ce dossier :

**Cas A - Le système actuel est déjà autorisé :**
- Joindre l'**arrêté préfectoral portant autorisation**, en cours de validité.
- Si l'extension modifie le périmètre (nouvelles caméras, nouvelles voies), joindre la **copie du dépôt du dossier de demande de modification** auprès de la préfecture.

**Cas B - Pas d'autorisation en cours :**
- Joindre la **copie du dépôt du dossier de demande d'autorisation** d'un système de vidéoprotection.

Rappels utiles :
- Une extension de périmètre nécessite une **modification de l'autorisation existante** : anticiper le dépôt, c'est une pièce qui conditionne l'éligibilité.
- La durée de conservation des images est encadrée par le code de la sécurité intérieure (30 jours maximum).
- Prévoir la **signalétique** informative sur la voie publique.
